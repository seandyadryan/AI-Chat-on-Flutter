Kebijakan Privasi NeuraX

Terakhir diperbarui: 8 Juli 2026

Kebijakan Privasi ini menjelaskan bagaimana aplikasi NeuraX mengumpulkan, menggunakan, menyimpan, dan melindungi data pengguna saat menggunakan layanan AI Chat.

1. Data Yang Kami Kumpulkan

Saat Anda menggunakan NeuraX, kami dapat mengumpulkan data berikut:

  • Informasi akun Google, seperti nama, alamat email, foto profil, dan ID pengguna.
  • Pesan atau pertanyaan yang Anda kirim ke fitur chat AI.
  • Jawaban AI yang dihasilkan untuk percakapan Anda.
  • Data teknis dasar seperti waktu akses, status request, dan data error untuk membantu perbaikan layanan.

2. Cara Kami Menggunakan Data

Data digunakan untuk:

  • Mengizinkan login wajib melalui Google.
  • Menyimpan riwayat percakapan agar dapat ditampilkan kembali di aplikasi.
  • Mengirim pesan pengguna ke server AI untuk menghasilkan jawaban.
  • Menjaga keamanan akun dan mencegah akses tidak sah.
  • Menganalisis gangguan teknis dan meningkatkan kualitas aplikasi.

3. Login Google Dan Firebase

NeuraX menggunakan Google Sign-In dan Firebase Authentication untuk memverifikasi identitas pengguna. Token autentikasi digunakan untuk memastikan bahwa hanya pengguna yang berhasil login yang dapat memakai fitur chat.

Kami tidak meminta password Google Anda. Proses login dilakukan oleh layanan Google/Firebase.

4. Penyimpanan Data

Data profil dasar dan percakapan disimpan di database PostgreSQL pada server Oracle Cloud yang kami kelola. Data percakapan digunakan untuk menampilkan riwayat chat dan memberi konteks pada jawaban AI.

5. Pemrosesan AI

Pesan yang Anda kirim diproses oleh model AI yang berjalan di server Oracle Cloud. Jangan mengirim data yang sangat sensitif, seperti password, kode OTP, data kartu pembayaran, dokumen rahasia, atau informasi pribadi yang tidak ingin Anda proses oleh sistem AI.

6. Berbagi Data

Kami tidak menjual data pribadi pengguna. Data dapat diproses oleh layanan pihak ketiga yang diperlukan untuk menjalankan aplikasi, seperti Google Firebase untuk autentikasi dan Oracle Cloud untuk server aplikasi.

7. Keamanan

Kami menggunakan koneksi HTTPS untuk komunikasi aplikasi dan membatasi akses database dari internet. Walaupun begitu, tidak ada sistem yang dapat menjamin keamanan 100%. Pengguna tetap disarankan untuk tidak mengirim informasi sangat sensitif ke chat AI.

8. Retensi Dan Penghapusan Data

Riwayat chat dan data akun dapat disimpan selama akun atau layanan masih digunakan. Anda dapat meminta penghapusan data akun dan percakapan melalui kontak yang tersedia di bawah.

9. Privasi Anak

NeuraX tidak ditujukan untuk anak di bawah usia yang diwajibkan oleh hukum setempat untuk menggunakan layanan digital tanpa persetujuan orang tua.

10. Perubahan Kebijakan

Kebijakan Privasi ini dapat diperbarui dari waktu ke waktu. Versi terbaru akan tersedia di halaman ini.
